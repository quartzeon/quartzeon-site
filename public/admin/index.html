Sign in with GitHub

Changes are saved to the repository on GitHub. Paste a token that can write to it.

  1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → this site's repository.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate it, copy it and paste it here. It is kept only in this browser.
